# Project NEXUS 🌌

> An interactive 3D AI Portfolio and Autonomous Career Command Center.

## 🏗️ Architecture
- **Frontend**: React 19, Vite, React Three Fiber (R3F), Zustand, Tailwind CSS v4, GSAP
- **Backend**: Python 3.13, FastAPI, SQLAlchemy 2.0 (Async), Pydantic V2/V3
- **AI Core**: LangGraph, LangChain, MCP, ChromaDB, Groq/Gemini
- **Infrastructure**: Docker, Redis, Postgres, GitHub Actions
